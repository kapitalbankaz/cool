# Cool Food — Restaurant Website

A fully static restaurant website for Cool Food, deployable on Render.com Static Site.

## Features
- ✅ Multi-page SPA (no URL changes)
- ✅ Menu with categories (Hot-Dog, Burger, Qəlyanaltı, Şorba, İçkilər, Extra)
- ✅ Product detail modal cards
- ✅ Shopping cart with WhatsApp order
- ✅ Reservation form with WhatsApp integration
- ✅ Gallery with lightbox
- ✅ FAQ accordion
- ✅ Vacancies with detail modal and WhatsApp application
- ✅ Contact section (WhatsApp, Instagram, Google Maps)
- ✅ Business hours section
- ✅ Fully responsive

## Tech Stack
- Pure HTML / CSS / JavaScript (no frameworks, no backend)
- All images stored locally in `/images/`
